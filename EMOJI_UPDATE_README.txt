Emoji picker update
===================

The chat interface now includes a larger emoji picker with:
- Recent and All tabs
- 10 emoji categories
- Search by English Unicode name or by pasting an emoji
- Skin-tone variants, country/territory flags, and common family/couple sequences
- Responsive layout for desktop and mobile

Files changed:
- templates/index.html
- static/emoji-data.js (new)

No backend routes or database schema were changed.
